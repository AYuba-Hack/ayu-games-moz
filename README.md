# AYU Games MOZ

Blog de jogos, dicas para Android e PC, segurança e conteúdos para jogadores em Moçambique.

Este repositório contém o código-fonte do website estático. A publicação pode ser configurada com Cloudflare Pages usando a pasta de saída `/` e sem comando de build.

> Os links de afiliados e anúncios devem ser adicionados apenas quando as campanhas e o website estiverem aprovados.

## Publicação e descoberta

O site utiliza Cloudflare Pages ligado à branch `main`. O `sitemap.xml`, `robots.txt` e o RSS `feed.xml` estão disponíveis na raiz. Para ligar ao Google Search Console, o proprietário precisa de verificar o domínio ou URL através dos métodos oficiais; não foi adicionada qualquer chave de verificação inventada.

O layout para ecrãs até 540 px usa cartões com miniaturas compactas, e a cache visual é renovada através dos parâmetros de versão dos ficheiros de estilo e JavaScript. A inclusão de publicidade ou links de afiliados exige aprovação e confirmação de condições das plataformas.
