# AYU Games MOZ

Blog de jogos, dicas para Android e PC, segurança e conteúdos para jogadores em Moçambique.

Este repositório contém o código-fonte do website estático. A publicação pode ser configurada com Cloudflare Pages usando a pasta de saída `/` e sem comando de build.

> Os links de afiliados e anúncios devem ser adicionados apenas quando as campanhas e o website estiverem aprovados.
